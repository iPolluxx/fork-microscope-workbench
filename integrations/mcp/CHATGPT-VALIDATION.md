# ChatGPT acceptance scope

Private ChatGPT acceptance covers actual tool discovery, grounded saved-data inspection/reports, original-byte retrieval and the deployed viewer. Synthetic fixtures prove software behavior; the published Qwen example contains real previously recorded model text. Reading it is not a fresh experiment.

Local stdio/Secure MCP Tunnel and the authenticated managed pilot are separate transports. A local host must stay reachable for new local reads; the pilot needs an authenticated hosted account and canonical OAuth link.

No private transcript, account identifier, app/tunnel mapping or credential is published here. [Viewer acceptance](VIEWER-VALIDATION.md) and [showcase validation](../../docs/chatgpt/VALIDATION.md) distinguish observed behavior from remaining gates. Historical success is not current compute readiness.
