TWEAK WITH A PURPOSE

Three controls that look alike.
Three different jobs.

WHERE

Checkpoint spacing

Smaller spacing checks more positions along the original output. It can narrow a change interval, but adds work.

HOW MANY

Draws per checkpoint

Each draw is a fresh continuation from the same prefix. More draws usually reduce sampling noise. They do not fill gaps between checkpoints.

HOW LONG

New-token cap

The maximum generated length of each continuation. Give the model room to finish. A capped reply goes to Other.

After a readout: test an internal-state replacement

In Explore → Look inside, the optional activation patch experiment replaces one selected state and compares fresh outcomes with unpatched and self-patch controls. Check the donor and recipient text first. The result tests that replacement; it does not prove why the original answer happened.

Standard readout capture stays the default. NNsight is an optional capture method on your own worker, not an agent connection or a hosted model service. New work needs the matching loaded model; saved artifacts need only a running viewer worker.
