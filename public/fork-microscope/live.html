Which workers and model formats can I use?

Model computation runs on the worker selected in the connection control. This page is served from . You can use your own machine or a GPU VM running Fork Microscope.

This adapter needs exact token IDs, next-token probabilities and forced-prefix generation. Native Transformers causal models and the text-only Muse adapter are eligible. Ollama/GGUF and ordinary chat API endpoints do not provide this workflow here.

Configure model access on the worker. Do not paste provider or Hugging Face keys into the model field. A local directory means a path on the worker, not a browser upload.

      Dots are collected outcome proportions; click a dot to read its continuations. Dashed lines reconstruct unsampled positions. Shaded vertical regions are fitted change intervals, never exact causal tokens. Drag across the graph to zoom.
      What do the uncertainty intervals mean?
      Point intervals are 95% Wilson intervals for one outcome at one checkpoint, calculated only from verified independent-mixture draw counts. They describe sampling uncertainty under this run’s retained-branch distribution. They are not simultaneous intervals or tests of a change. Fitted bands are nominal 90% model-based marginal bands from the reconstruction and can be miscalibrated. Neither accounts for excluded branches or answer-matching errors.
      Inspect change intervals
      Compare adjacent sampled outcome distributions, then read the original text between them. These differences can be sampling noise. Fitted intervals appear first; remaining intervals are ordered by observed difference across all outcomes.

      Method and interpretation
      At each checkpoint we choose branches by renormalized temperature-1 probability, then generate the requested number of total draws. Every collected outcome enters the histogram and reconstruction exactly once. Each pass is fitted separately. More than 10% cap hits withholds reconstruction; fewer than four checkpoints disables segmentation and CV.
      Changing models does not reproduce the published numerical results. PELT boundaries are candidate changes between observations; they do not identify a causal token. Credible bands are model-based and can be miscalibrated. A separate dense run permits comparisons without reusing the fitting continuations.
      Muse uses its native image/text model loader and text-only chat template. Other compatible models must load with Hugging Face AutoModelForCausalLM and safetensors, fit this runtime, and support text generation in the installed Transformers version. Architectures requiring custom remote code or unsupported quantization are not automatically supported. Muse matches use its completed user-facing channel. For generic models we strip an explicit <think>…</think> prefix when present; untagged reasoning may still match. Matching detects literal mentions, not correctness. Multiple matches, no matches and unfinished replies count as Other. Historical A–D runs retain their original parser. This version uses standard batched generation, without the cross-branch prefix-cache speedup. No custom model code is executed.
